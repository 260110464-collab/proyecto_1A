Problemática

En esta sección se describirán los dos problemas asignados, sus dificultades y la importancia de encontrar una solución mediante la programación.

Análisis de resultados

Problema 1: Módulo Geométrico-Vectorial

Este módulo permite calcular la distancia entre dos puntos a partir de sus coordenadas. Para obtener el resultado se utiliza la fórmula de la distancia euclidiana, tomando en cuenta las diferencias entre las coordenadas X y Y.

Se realizaron diez casos de prueba que incluyeron coordenadas positivas, negativas y decimales, puntos iguales, distancias verticales y entradas incorrectas. Los diez casos se ejecutaron satisfactoriamente. El programa calculó correctamente las distancias y rechazó los datos inválidos o fuera del rango permitido.

Problema 2: Módulo Financiero-Lógico

Este módulo calcula los impuestos aplicables al precio de un equipo de acuerdo con dos condiciones lógicas: si el comprador es un estudiante acreditado (P) y si el equipo pertenece al catálogo educativo (Q).

Se comprobaron las cuatro combinaciones posibles de las condiciones. Cuando ambas son verdaderas se aplica un impuesto del 0%; cuando solamente una es verdadera se aplica el 8%; y cuando ambas son falsas se aplica el 16%.

También se realizaron pruebas para verificar el rechazo de precios negativos, precios iguales a cero, textos en el precio y valores inválidos en las proposiciones P y Q. En total, los diez casos de prueba se ejecutaron satisfactoriamente. El programa rechazó las entradas incorrectas y permitió ingresar valores válidos posteriormente.

En general, los resultados de las pruebas permitieron comprobar que ambos programas realizan correctamente sus operaciones y cuentan con validaciones para evitar entradas incorrectas.

Conclusión

La realización de este proyecto integrador permitió aplicar los conocimientos adquiridos sobre programación en Java, lógica algorítmica y resolución de problemas. Mediante el desarrollo de los dos módulos se comprendió la importancia de analizar las condiciones de cada problema antes de implementar una solución.

En el módulo Geométrico-Vectorial se logró calcular correctamente la distancia entre dos puntos mediante operaciones matemáticas y validaciones de entrada. Por otra parte, en el módulo Financiero-Lógico se aplicaron condiciones lógicas para determinar los porcentajes de impuestos y calcular el total a pagar.

Las pruebas realizadas permitieron comprobar el funcionamiento de ambos programas, identificar posibles entradas incorrectas y verificar que las validaciones respondieran adecuadamente.

Finalmente, el trabajo en equipo y el uso de herramientas como Git y GitHub facilitaron la organización de las actividades, el control de versiones y la colaboración entre los integrantes. Este proyecto reforzó nuestros conocimientos y habilidades para desarrollar soluciones mediante la programación.
